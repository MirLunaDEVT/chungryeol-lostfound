# 🏫 충렬고등학교 분실물 찾기 - 교내 분실물 찾기 & 커뮤니티 플랫폼

> **"중고거래가 아니라, 잃어버린 소지품을 안전하고 빠르고 확실하게 주인에게 돌려주는 학교 전용 플랫폼"**
>
> 외부인 침입, 익명 장난 게시, 허위 수령을 원천 차단하고 실명 기반 신뢰 체계와 엄격한 학생실 인수인계 프로세스를 구현한 웹 애플리케이션입니다.

---

## 📌 주요 특징 및 해결 과제

1. **학교 구성원 100% 한정 인증 (외부인 차단)**
   - **학교 Google Workspace OAuth 2.0**: `hd`(hosted domain) 제한으로 학교 발급 계정(`@student.school.hs.kr`, `@school.hs.kr`)만 로그인 허용.
   - **재학생 명단(Roster) 대조 학번 로그인**: 관리자가 업로드한 재학생 마스터 명단에 존재하는 학생만 학번+이름 대조 후 최초 1회 인증(PIN/비밀번호 해시 저장).
   - **졸업/전학 처리**: 관리자가 명단에서 제외(`enrolled: false`) 시 즉시 로그인 권한 박탈 및 기존 글은 '탈퇴 회원' 처리.

2. **허위 수령 원천 차단 (공식 클레임 상태머신)**
   - 게시글 작성 시 고유 식별 특징(케이스 안쪽 스티커, 안감 색상, 내부 소지품 등)은 **비공개**로 겉모습만 등록.
   - 분실자가 "내 물건이다" 주장 시 **수령 신청(Claim)** 퀴즈를 제출.
   - 습득자 또는 교사/관리자 승인(`APPROVED`) 시에만 인수인계 장소 확정 및 1:1 안전 대화방 개설.
   - 오프라인 학생실(학생안전복지부)에서 실물 대조 후 **[반환 완료]** 처리 시 글 잠금 및 대화방 읽기 전용 전환.

3. **초고속 매칭 및 키워드 알림**
   - 학생이 "에어팟", "체육복" 등 키워드를 구독해두면 해당 단어가 포함된 새 글 등록 시 인앱 실시간 알림 발송.
   - 분실 글과 습득 글 간 카테고리 + 장소 + 등록 7일 이내 유사 글 추천 배너(`SimilarPosts`) 자동 연동.

4. **철저한 교내 악용 방지 장치**
   - **전체 실명제**: 익명 옵션 전면 배제. (학번은 마스킹 `2401**` 표시, 교사는 '교직원' 표기)
   - **사진 필수**: 분실/습득글은 사진 1장 이상 등록 필수 (장난글 방지).
   - **작성 속도 제한**: 계정당 10분 내 1건, 하루 최대 5건 등록 제한. 끌어올리기는 글당 1일 1회, 총 3회 제한.
   - **사적 연락 방지**: 댓글 및 채팅창 내 휴대전화번호(`010-XXXX-XXXX`) 및 외부 메신저 링크(`open.kakao.com`) 패턴 감지 시 보안 주의 경고 및 차단 알림.
   - **신고 자동 숨김**: 동일 글에 3건 이상 신고 접수 시 피드에서 즉시 자동 숨김 처리 후 관리자 심사 큐로 이동.
   - **금칙어 필터**: 교내 비속어 및 금칙어 사전 실시간 검사.
   - **보안 감사 로그**: 로그인 실패, 신고 접수, 계정 정지, 상태 변경 등 모든 보안 이력 영구 기록.

## 🛠 기술 스택

- **Frontend**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **Backend**: Next.js Route Handlers (REST API, 철저한 세션 및 RBAC 권한 검증)
- **Database**: SQLite (개발/데모 무설정 즉시 실행) / PostgreSQL (환경변수 `DATABASE_URL` 전환 완벽 호환)
- **ORM**: Prisma ORM v5
- **Auth**: NextAuth.js (Google OAuth Provider + Roster-verified Credentials + 1-Click Demo Switcher)
- **Storage**: Local sanitized storage (`/public/uploads`, MIME 타입/매직바이트/크기 검증 및 EXIF 메타데이터 제거)
- **Icons**: Lucide React

## 🚀 빠른 시작 (Local Development)

Node.js (v18 이상 권장, v22 지원) 환경에서 1분 안에 실행할 수 있습니다.

### 1. 저장소 클론 및 패키지 설치
```bash
npm install
```

### 2. 환경변수 설정
`.env` 파일이 기본 생성되어 있습니다. 로컬 테스트 시 별도의 구글 콘솔 설정 없이도 **즉시 실행 및 테스트**가 가능하도록 구성되어 있습니다.
```bash
cp .env.example .env
```

### 3. 데이터베이스 생성 및 시드 데이터 적재
```bash
# DB 스키마 생성 (SQLite dev.db 자동 생성)
npx prisma db push

# 데모 데이터 적재 (교사 1명, 학생 5명, 분실/습득글 8개, 신고 1건, 사물함 3개)
node prisma/seed.js
```

### 4. 로컬 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000` 접속!

## ⚙️ Google Cloud Console OAuth 2.0 설정 가이드 (실제 학교 적용 시)

학교 구글 계정(@student.school.hs.kr) 로그인을 운영 환경에 적용할 때 설정할 항목입니다:

1. [Google Cloud Console](https://console.cloud.google.com/) 접속 후 새 프로젝트 생성 (예: `SchoolFound-Production`).
2. **OAuth 동의 화면**:
   - 사용자 유형: **내부(Internal)** 선택 (학교 Google Workspace 조직 구성원만 접근 가능).
   - 앱 이름, 사용자 지원 이메일(`teacher@school.hs.kr`) 입력.
   - 승인된 도메인: `school.hs.kr`
3. **사용자 인증 정보 > OAuth 클라이언트 ID 만들기**:
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 자바스크립트 원본**:
     - 로컬: `http://localhost:3000`
     - 운영: `https://lost.school.hs.kr`
   - **승인된 리디렉션 URI**:
     - 로컬: `http://localhost:3000/api/auth/callback/google`
     - 운영: `https://lost.school.hs.kr/api/auth/callback/google`
4. 발급된 클라이언트 ID와 클라이언트 보안 비밀번호를 `.env` 파일에 기입:
   ```env
   GOOGLE_CLIENT_ID="발급받은_클라이언트_ID"
   GOOGLE_CLIENT_SECRET="발급받은_시크릿_키"
   GOOGLE_ALLOWED_DOMAINS="student.school.hs.kr,school.hs.kr"
   ```

## 📁 재학생 마스터 명단 CSV 업로드 형식

관리자 페이지(`/admin/roster`)에서 학기 초 재학생 명단을 엑셀/CSV로 일괄 업로드할 수 있습니다.

### CSV 파일 예시 (`roster_sample.csv`)
```csv
학번,이름,학년,반,역할
240101,김민우,1,2,STUDENT
240102,정서윤,1,1,STUDENT
230205,이지은,2,3,STUDENT
230212,박준혁,2,3,STUDENT
220115,최수아,3,1,STUDENT
T9901,김교사,null,null,ADMIN
```
- **학번**: 6자리 고유 학번 (교원은 교번)
- **이름**: 실명 (구글 계정 이름이나 온보딩 시 엄격 대조)
- **역할**: `STUDENT`, `TEACHER`, `ADMIN` (교사 권한을 학생이 스스로 선택할 수 없음)
- **졸업/전학 조치**: 관리자 테이블에서 [재학(정상)] 버튼을 클릭하면 [제외(차단됨)]로 전환되어 즉시 로그인이 거부됩니다.

## 📋 학교 관리자 승인 필요 항목 체크리스트

학교 실서버 배포 및 공식 오픈 전 학교 운영위원회 / 교무회의에서 확정 및 승인이 필요한 항목입니다:

- [ ] **1. 허용 구글 로그인 도메인 확정**:
  - 학생용 도메인(`student.school.hs.kr`)과 교직원용 도메인(`school.hs.kr`) 분리 여부 확인.
- [ ] **2. Google Workspace 관리자 콘솔 설정**:
  - Google Cloud OAuth 앱을 교내 도메인 전용 '신뢰할 수 있는 앱'으로 지정.
- [ ] **3. 재학생 마스터 명단 CSV 데이터 수합**:
  - 나이스(NEIS) 학적 명부 기반으로 최신 학번/이름 CSV 추출 및 관리자 업로드 준비.
- [ ] **4. 공식 분실물 인수인계 장소 확정**:
  - 기본값: `본관 1층 학생안전복지부 분실물 보관함`
  - 사물함 번호 체계(`L-01` ~ `L-10`) 및 담당 교사 배정.
- [ ] **5. 교내 개인정보 처리방침 문구 학교운영위원회 심의**:
  - `/privacy`에 기재된 수집 항목(학번, 이름, 이메일), 목적, 보유 기간(졸업 시 차단, 반환 후 90일 보관 후 파기) 학교 규정 부합 여부 승인.
- [ ] **6. 학생 생활지도 규정 반영**:
  - 허위 수령, 고의적 장난 게시 및 사칭 시 학교폭력/선도위원회 회부 기준 사전 공지.

## 📱 주요 화면 라우트 안내

- `/`: 메인 피드 (전체/분실/습득/커뮤니티 탭, 카테고리 가로 스크롤, 건물 필터, 핀 공지, 글쓰기 FAB)
- `/login`: 학교 구글 로그인 & 학번/명단 로그인 & 데모 스위처
- `/onboarding`: 최초 구글 로그인 학생의 학적 대조 인증 & 3단계 안전 가이드
- `/posts/new`: 분실/습득물 30초 등록 폼 (사진 업로드, 태그, 인라인 수칙 가이드)
- `/posts/[id]`: 상세 페이지 (사진 캐러셀, 식별 퀴즈 수령 신청, 유사 글 추천, 목격 제보 댓글, 공감 반응)
- `/search`: 물품명/장소/키워드 검색 및 추천 태그
- `/alerts`: 관심 키워드 알림 구독 & 인앱 알림함
- `/chat`: 진행 중인 1:1 안전 대화 목록
- `/chat/[id]`: 1:1 대화방 (전화번호/외부링크 경고 감지, 반환 완료 잠금, 차단/신고)
- `/me`: 마이페이지 (내 정보, 신뢰 반환 기여 지표, 내 게시글)
- `/admin`: 관리자 대시보드 (통계 지표, 보안 감사 로그)
- `/admin/roster`: 재학생 명단 CSV 업로드 및 재학/졸업 토글
- `/admin/reports`: 신고 심사 큐 (이상 없음, 글 숨김, 경고 부여, 계정 정지)
- `/admin/users`: 사용자 계정 제재 및 역할 관리
- `/admin/banned-words`: 교내 비속어/금칙어 사전 관리
- `/admin/lockers`: 학생실 실물 보관함(사물함) 현황
- `/admin/notices`: 메인 피드 상단 고정 공지 등록
- `/privacy`: 교내 개인정보 처리방침
