# 🏫 충렬고등학교 분실물 찾기

충렬고등학교 구성원을 위한 교내 분실물 안전 반환 및 소통 웹 플랫폼입니다.

---

## 📌 주요 기능

- **교내 구성원 인증**: 충렬고등학교 공식 Google Workspace 계정(`@pscr.hs.kr`) 및 학적 명단 기반 인증
- **분실 / 습득물 등록**: 교내 물품 사진 및 습득 장소 등록
- **안전 수령 예약**: 물품 고유 특징 퀴즈 확인 및 학생실 방문 예약
- **키워드 알림**: 관심 물품 키워드 등록 시 실시간 인앱 알림

---

## 🛠 기술 스택

- **Frontend / Backend**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **Database**: PostgreSQL (Prisma ORM)
- **Authentication**: NextAuth.js
